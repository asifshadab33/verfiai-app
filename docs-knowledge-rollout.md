# Knowledge Index and Evidence Library rollout

## Architecture and scope
- `/knowledge` lists editorially approved publisher links, and can query Crossref live for publication metadata. Search results link to DOI originals; they are not hosted or vouched-for research. `/resources` lists reviewed library metadata. `/resources/$slug` shows publisher, original URL, licence/reuse text, verification date, source references and preview; `/account/library-usage` shows actual billing-period usage. Local-only bookmarks never leave the browser.
- `src/lib/library.functions.ts` exposes bounded server queries, issue submissions, and authenticated download/allowance endpoints. `src/components/verifai/ResourceBrowse.tsx` handles browsing. `drizzle/migrations/0005`–`0008` create rights, references, issues and quota tables, hide full content from public database SELECT, scope quota to billing environment, and revoke the legacy environment-agnostic function. `src/integrations/supabase/types.ts` is regenerated.
- Rights are default-deny (`PENDING_REVIEW`). Only approved metadata is browsable; `LINK_ONLY` and `RESTRICTED` are never hosted/downloaded. Library downloads require approved rights, hosting and redistribution permission, and commercial-use evidence for partner/open licences; a current Analyst subscription in the server-selected payment environment; an atomic 50-per-real-billing-cycle quota. Repeat downloads of the same version do not consume an extra slot. The authenticated POST streams content to the browser for an immediate Markdown blob download; no permanent public file URL is created. Previews and publisher links do not count.
- Existing $9/month Pro and its report limits remain unchanged. Analyst price, product registration and checkout are **not configured**; the allowance is visible only to an account with a valid Analyst subscription record. No claim is made that any curated resources have passed rights review; the library is empty until reviewed items are added.

## Rollout and operational safeguards
1. Configure the existing Supabase and Paddle secrets using `.env.example` as a **names-only** template; do not commit actual values. Apply migrations 0005–0008 in numerical order using the project's database migration process. Check column-level grants and the SECURITY DEFINER function before publishing resources.
2. Curate each index/library entry: confirm publisher, original URL, current rights/permissions, licence and third-party excerpts, region/language, source URLs, original date and `verified_at`. Set `published=true` only after review. Open-licensed and partner material requires recorded permission reference, rights review date, commercial permission, and separately confirmed redistribution/hosting. Verify that takedown/unpublished rows disappear and previously granted download access is blocked.
3. Keep Analyst checkout disabled until product owner supplies price, billing policy and Paddle product mapping. Extend webhook verification for the approved Analyst product/price in a separate release; current webhook accepts only Pro. Confirm sandbox checkout, renewal, cancellation and quota reset before a live launch.
4. Review security: unauthenticated requests must not read `full_content` or histories; a user must not read another user's issues/downloads; test concurrent downloads at 49/50, same-version idempotency, unauthorized/expired/other-environment subscription rejection, rights revocation, malformed inputs, and absence of cached private response bodies. For high-volume catalogs, add database full-text search and pagination before scaling (current browse returns at most 40 reviewed rows per filter).
5. QA: keyboard/filter/mobile/RTL layout, accurate publisher/licence links and verification timestamps, Crossref outages, empty state, issue reporting, all routes, no regression to report creation or Pro $9 checkout. Verify actual licensed content before announcing availability. Add abuse monitoring and rate limits before opening public issue reporting at scale.
6. Rollback: unpublish catalog items and hide the navigation links first; revoke download-function EXECUTE if rights or metering fail. Keep download history for audit. Revert migrations only after preserving records and evaluating existing subscriptions; never restore full_content read grants.

## Unresolved decisions / limitations
- Analyst product, price, checkout and entitlement webhook are pending. The latest request says **50** downloads per cycle (the uploaded brief said 100); 50 is enforced. Pro does not include Analyst downloads until product owner defines a separate allowance.
- No verified catalog content has been supplied, so curated catalog lists are initially empty; Crossref metadata is live but unreviewed and is explicitly labelled as such. Library Markdown synthesis files require editorial rights review before publishing.
- No signed-storage links are needed while serving authorized Markdown directly in a short-lived POST response. A future binary-file storage implementation should use short-lived signed URLs after atomic quota reservation.
- The broad uploaded master brief's team/enterprise, collaboration, organizational billing, granular cost accounting and advanced ranking pipelines are not implied to be complete by this focused catalog release.
